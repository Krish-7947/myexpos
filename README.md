# Expos NITC OS Lab Project

**Expos NITC** is a lab-based operating systems project built incrementally across a series of guided stages. This repository contains the stage-wise implementation artifacts developed while working through the project.

For full project details, documentation, and specifications and tutorial for running the os, see: **https://exposnitc.github.io/**

---

## Overview

The project is implemented incrementally across **27 lab stages**. Each stage introduces a new OS concept, starting from low-level machine fundamentals and filesystem layout, and progressing through interrupt handling, multiprogramming, process synchronization, file management, user management, and virtual memory (paging), culminating in a fully functional system with login, a shell, and file utilities.
